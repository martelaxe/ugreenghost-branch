This is a comparison of guidance, not executing or validating the Skill in UGREEN.

Freeze case facts and [expected outcomes](keys/scoring-key.md) before runs; place only the case data in each namespace. Protect key at the project mount and don't pass case labels/expected results in prompts. Record all failures and raw events. Score by direct evidence, actual path resolution, precision on direct vs inferred effects, target and scope handling, truthful coverage and whether a useful safe next action is delivered. No human users participate. Reviewer knows method and created cases, so assessment is not blinded. Source paths checked manually plus automated backtick path checks; a path match is not semantic proof.
