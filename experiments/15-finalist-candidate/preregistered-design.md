## Post-observation fixture amendment: second wave

The first-wave baseline S and irrelevant G/S treated the volunteer-coverage requirement as UNKNOWN because the fixture gave event opening/closing times but no individual volunteer shift times. Baseline G treated that requirement as PASS. This exposes an ambiguity in the original fixture and invalidates the original assumption that it unambiguously supports all three checks. These observations are retained and are not retroactively relabeled. Before running a second wave, add an explicit fictional shift roster to the otherwise identical event baseline and each event mutation/restriction variant. The changed relevant source and changed irrelevant source remain one-file differences versus that amended baseline. The same frozen Skill and same G/S prompts are used on all five amended cases, generating entirely separate outputs and workspaces; no v1 output is treated as contemporaneous with v2. This is a post-hoc fixture repair, not an independent preregistered replication. Its positive baseline asks whether the method behaves when the previously ambiguous evidence is actually supplied; it does not erase the observed disagreement or make the larger study statistically conclusive.

## Post-observation date amendment: third wave

The v1 business Skill response correctly observed that a purportedly completed April 2027 workshop was in the future relative to the real 2026-10-27 system date, and that its payment record had no date supporting “current.” The v2 event rights record likewise bears a future 2027 signature relative to the real date. These are fixture-design defects, not model errors. Preserve both earlier waves. Before v3, define the same explicit fictional assessment date, 25 April 2027, in the user request for every condition, and supply a dated current payment record in the business fixture. Run all five cases under both G and S again with the same frozen Skill and identical per-case data, in separately stored workspaces. No v2 outcome is compared as if it used the v3 prompt. This third wave is post-observation repair and is not an independent prospective replication; the earlier ambiguity and date defects remain material limitations.
