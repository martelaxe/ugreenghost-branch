# Experiment 02 — Unexpected Opportunity Discovery

A controlled, two-variant local Codex experiment. Each fictional archive contains 22 files; one licensing clause changes between variants. No NAS integration or hackathon submission is included.

- `datasets/archive-a/` and `datasets/archive-b/`: fictional source archives.
- `private/answer-key.md` and `private/rubric.md`: preregistered expectations and scoring; keep out of future blind investigator workspaces.
- `results/archive-a-report.md` and `results/archive-b-report.md`: exact independent investigator outputs. Evidence links in these reports are relative to the respective archive workspace; inspect the matching dataset to follow them.
- `results/comparative-evaluation.md`: scoring and evidence after both sessions finished.
- `execution/execution-record.md`: setup, process details and isolation limitations. The directory also includes the exact prompt, preregistration hashes, variant diff, source manifest, process status, event logs and stderr.
- `lessons-learned.md`: conclusions and suggested next steps.
