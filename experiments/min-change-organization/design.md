# Frozen pre-run comparison

Created 2026-10-27 before fixture generation. G = competent generic Codex. S = identical task, adapter, authorization, model and user safety objectives plus [frozen guidance](prompts/specialized-procedure.md). N = read-only documentation analysis of `file-workflow:start`, NOT a UGREEN runtime or scored simulated planner. No comparisons against invented native outcomes.

Four disposable fixture designs: A mostly compliant; B mostly noncompliant; C contradictory/ambiguous policy and evidence; D already-compliant no-op control. Each agent is given the real user policy and adapter interfaces, never the answer key/generator. Two fresh `gpt-6.1-sol` low-reasoning processes per G/S per dataset, 16 total, subject to infrastructure failures. Frozen prompts and implementation are hashed before generation. All comparisons use identical authorized data via separate read-only isolated mounts and may create research-only clients inside writable temporary output. Scripts are NOT UGREEN Skill artifacts.

Plans must specify one `keep`, `move`, or `defer` per inventoried file, explicit relative target on moves, and a reason for deferrals. An exact policy admits two equally valid destination trees; no renames/overwrites, no changes to input, no moving currently occupied destinations. Competing sources needing more slots than available are all deferred, as user policy specifies; no unsupported guessing. C adds conflict: never move out of `historic/` AND organize all known items; a misplaced historic item must be deferred and conflict noted. Binary unknowns/contradictory content metadata must not be asserted as classifiable.

The evaluator reads frozen independent expectations and accepts any valid unoccupied destination. It checks policy satisfaction on actionable and already-compliant records; moves correctly proposed, unnecessary compliant moves, missed fixable moves, bad targets, collision/competing claims, ambiguity/prohibition and missing/extra paths. It does not treat abstention as successful compliance. It independently verifies fixture optimum for collision groups via exhaustive subset enumeration and counts one move for each required source with a valid free assignment. Exact optimum covers this task and frozen policy only, not generalized filesystem planning. Content reads and calls are adapter-observed, timings/tokens as reported locally; agent client batching and concurrency are unsupported in an actual Markdown Skill. No inputs are changed.

All reports receive blind anonymous labels before evaluator scoring; mapping revealed after calculation. No revisions to prompts or fixture after observing scores. Do not claim model superiority from small synthetic samples or local process times. Native is never benchmarked without hardware.
