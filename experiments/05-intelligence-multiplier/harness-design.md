# Research-only investigation harness

The harness is a local Python controller outside any UGREEN Skill. It uses no dataset-specific terms or answer-key paths. It performs bounded recursive inventory of TXT/MD/CSV/JSON evidence, rejects symlinks and binary/undecodable content, reads at most 8,000 bytes per file and 200,000 bytes overall, and records paths, byte counts, omissions and truncation. The limits and retrieval manifest are part of each result. The candidate and verifier each receive the same retrieved corpus with file boundaries; source text is untrusted and must not be treated as instructions.

H performs two fresh `codex exec` model calls with the same explicit `gpt-6-luna` / `low` configuration as G/P: (1) open-ended candidate generation from the corpus; (2) a separate session evaluates the candidate against the same corpus, checks blockers and proposes a cautious conclusion. The code then independently checks each final `path` and exact quoted excerpt against the retrieved file text; a candidate with any unsupported quote, an invalid path, or fewer than two distinct cited paths is rejected. It cannot prove semantic entailment, current truth, adequate retrieval, the absence of hidden blockers, or real legal compliance. It carries coverage warnings into the final report. If structured output is malformed or the verification stage returns no candidates, it abstains instead of fabricating a result. No hard-coded answer, roles, fixture identifiers or domain-specific blocker rules are used.

H is more than a longer prompt: local retrieval, input accounting, fresh verifier call and deterministic source-quote filtering are additional operations. The execution records include two model calls per H trial, CLI token usage, wall-clock time, files/bytes retrieved and omitted/truncated paths. The verifier may still make reasoning mistakes, and lexical evidence checks do not establish that a quote supports a claim. G/P can inspect the same files directly and may retrieve them differently. Reports, raw model messages, and CLI event logs are preserved. This is an experimental harness and cannot be packaged into an official UGREEN Skill.
