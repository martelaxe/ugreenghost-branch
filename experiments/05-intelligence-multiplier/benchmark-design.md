# Benchmark design

Three 44-file synthetic archives, authored by the experimenter, use mixed TXT, Markdown, CSV and JSON; a referenced PDF is intentionally absent. A and B differ in exactly one permissions clause; C is a separately modified negative control but shares many ordinary records, limiting independence. All source paths and SHA-256 hashes are in `execution/source-manifest.json`, and the A/B change is in `execution/ab-diff.patch`. The frozen private answer and rubric identify six evidence units, barriers, traps and alternate-solution criteria.

Each of G and P uses a fresh Codex process with identical explicit `gpt-6-luna`, `low` configuration, read-only sandbox, disabled web search and no user config; prompts differ only in P's extra reasoning procedure. H uses deterministic local inventory/retrieval and citation validation plus two fresh calls to the same configured model: candidate generation, then independent verification and critique. Its model calls and input budget are greater; do not treat H as a single-prompt treatment or infer that additional operations are free. Each condition sees the same 44 source files; H receives an explicit bounded text copy, while G/P may choose how to read files. Any observed difference is a bundled workflow-plus-compute difference, not evidence that a model became intrinsically stronger.

Plan: 3 archives × 3 methods × 2 replicates = 18 independent investigations; each H investigation has two independent model sessions. Save exact prompts, workspaces, event logs, outputs, token usage and process status. Do not retry incorrect reasoning. Model backend identity is not echoed by the CLI event stream; explicit configuration plus the successful preflight is the available evidence.

Evidence isolation: each session gets a workspace containing only its assigned archive and is instructed to stay inside it. The Codex read-only sandbox is not a filesystem-read isolation boundary. Protect the project and prior-experiment directories with temporary permissions during runs where safely possible; sibling workspaces share a parent/user and the authentication/model backend. Audit observed shell commands and disclose limitations.

After all reports, use a separate evaluator where feasible and remove method labels, or else report that evaluation is not independent/blinded. Score according to the frozen rubric and inspect citation text against source evidence. Report per-run facts and descriptive statistics; no significance or generalization claim.
