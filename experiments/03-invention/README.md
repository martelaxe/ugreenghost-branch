# Experiment 03 — The Invention Test

A synthetic, preregistered comparison of generic and specialized Codex investigators across three 60-file archives and 12 valid independent sessions. This is local research, not a UGREEN Skill or submission.

- [Research plan](research-plan.md) and [frozen answer key](private/answer-key.md) / [rubric](private/rubric.md).
- `datasets/archive-a/`, `archive-b/`, `archive-c/`: fictional evidence archives. A and B differ in one equipment-service sentence; C is a separate restricted negative-control organization.
- [Generic](prompts/generic.txt) and [specialized](prompts/specialized.txt) exact prompts.
- [Comparative evaluation](comparative-evaluation.md), [failure analysis](failure-analysis.md), [untested Workflow S2](workflow-s2.md), [UGREEN feasibility](ugreen-feasibility.md) and [product differentiation](product-differentiation.md).
- `results/*-retry.md`: 12 independent final reports. Evidence paths inside a report are relative to its assigned archive, not to the report location. Original `results/*.md` without `-retry` are preserved failed technical attempts.
- [Execution record](execution/execution-record.md): manifests, diffs, preregistration hashes, event logs, timing and blinding limitations are in `execution/`.
- [Decision memo](../../docs/experiment-03-decision-memo.md).

The local experiment does not demonstrate supported NAS runtime behavior. The research tooling in `tools/` is for reproducibility and is not part of a UGREEN Skill package. Do not copy the answer key, plans, results or prompts into investigator workspaces.
