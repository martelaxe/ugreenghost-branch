# Experiment 16 — Project Rescue

Start with [evaluation](evaluation.md), [demo before/after](demo/before-after.md), [technical feasibility](../../research/16-project-rescue/technical-feasibility.md), [judge review](../../research/16-project-rescue/judge-review.md), and [decision memo](../../docs/experiment-16-project-rescue-decision.md). Fictional [creative and business fixtures](fixtures/) are separate from [answer keys](answer-keys/); raw investigator inputs, responses, tool events and hashes are in `runs/`. The selected Skill was frozen and static checked before the model comparisons. Research scripts are outside the Skill package.

The recorded real copy was local Python in a disposable clone under synthetic approvals. Neither the Codex model nor a UGREEN expert performed a write. The post-copy unavailable case was a hypothetical prompt; a separately controlled local adapter test exercises an actual copy followed by injected readback failure. Seven deterministic local checks are recorded in [adapter-test-results](adapter-test-results.txt); they are not tests of UGREEN enforcement. Two model reports overcounted the fixture, and raw sandbox links are nonportable. This experiment does not establish generic-AI superiority or human preference.
