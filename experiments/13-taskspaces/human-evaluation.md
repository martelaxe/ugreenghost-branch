# Next validation: blinded human task walkthrough

No users have been contacted. Use synthetic future-event data only. Prepare two unlabelled, equal-format printouts from `wow-case/future/runs/G/response.md` and `wow-case/future/runs/T/response.md`, with their source citations preserved and original response text unchanged. Randomize which version is A/B and record the mapping separately; remove agent labels. Ask a willing NAS owner or event organizer to use one draft to identify: the correct venue/date, a photo they can publish, an approved graphic, what they still need to ask, and how they would use the handoff. Counterbalance ordering across participants. Then ask the same questions for the other draft and ask which would make their work easier and why, including what felt redundant or confusing. Time only with consent; record wrong decisions and unknowns, not just preference. Do not describe one as the expected winner.

Successful evidence would be at least one observed independent user completing the concrete tasks and explaining a meaningful difference; a small walkthrough is exploratory and cannot establish population preference. If the drafts perform similarly, Taskspace's added value remains unproven. If either draft obscures that the graphic is only described in text, treat it as a substantive output failure. Separately test actual UGREEN expert returns, no-overwrite/approval and source paths when finalist hardware is available. No public release or outreach is performed by this experiment.
