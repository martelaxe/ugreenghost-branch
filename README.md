# UGREEN Ghost Branch

Ghost Branch is a proposed UGREEN Uliya Skill that helps developers investigate forgotten implementations in authorized NAS project backups, compare them with current files, and prepare an evidence-backed decision handoff.

Start with the [Skill](prototype/ghost-branch/SKILL.md), [final assessment](docs/ghost-branch-final-decision.md), [local test report](experiments/ghost-branch/test-report.md), and [Round 1 draft](submissions/round1-ghost-branch-draft/README.md). The draft [proposal PDF](submissions/round1-ghost-branch-draft/ghost-branch-proposal.pdf) and [Skill ZIP](submissions/round1-ghost-branch-draft/ghost-branch-skill.zip) are included for review; they have not been submitted.

The Skill passed UGREEN's static checker, but has not been tested on a UGREEN NAS. Local generic agents also found the main examples, so a discovery advantage has not been established. The repository contains earlier research, prototypes and fictional test fixtures; their results should not be treated as NAS runtime evidence.

## Original project description

A starting point for a UGREEN AI NAS hackathon idea: help someone organize files and discover useful, evidence-backed connections across them. The concept is exploratory; its name and final scope are not decided.

## Start here

1. Read `docs/experiment-01.md` for the scenario and how to run a blind investigation.
2. The 12 documents under `experiments/01-studio/fictional-files/` are entirely fictional. They are the input.
3. `experiments/01-studio/answer-key.md` is for scoring only. Keep it away from the investigator until after their answer is recorded.
4. `docs/capability-audit.md` maps the idea to the official UGREEN creation kit and its limitations.

No file organizer, NAS integration, timeline, or restoration system has been implemented. A local investigation is not evidence of NAS runtime behavior. Nothing here is a finished competition submission.
