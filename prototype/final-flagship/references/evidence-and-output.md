# Evidence and decision preview

Preserve each actual source path or stable identifier and excerpt if returned. Distinguish exact references, inferred consequences, contrary evidence and unresolved possibilities. Do not manufacture excerpts, file counts, paths, timestamps, approval states or missing source evidence. Match the requested paths to the expert's actual returned results; if correspondence is unclear, mark it unknown.

Report only counts supported by the completed returned inventory or explicit per-file results. State selected sources separately from discovered sources; a selected document is not successfully read unless supported by a completed result. If the listing meets a cap, is inaccessible, truncated, returns a partial state or does not establish completeness, report scope as incomplete or unknown. Do not assume pagination or declare all files checked. Runtime applications, external shares, unreadable files and later changes are outside the observed evidence unless explicitly supported.

## User-facing output

1. **Proposed change:** actual target and intended action; no action executed.
2. **What may be affected:** at most three prioritized evidence-backed relationships, with source paths and actual excerpts when returned; clearly label direct references versus interpretation.
3. **Copies and roles, if requested:** actual selected paths, observed hash comparison if available, supported roles and unknowns. A hash cannot establish permission to delete.
4. **What is unknown:** ambiguity, inaccessible/missing sources, unknown application usage, missing coverage, partial results and relevant scope limitations.
5. **Next safe step:** one concrete verification or user decision appropriate to the evidence; do not certify a move/deletion as safe.
6. **Coverage and state:** authorized roots, requested limits and actual counts or identifiers only if available; reviewed versus not reviewed; completed/partial/waiting/failed/cancelled as appropriate.

When no connection is substantiated, explicitly say none was found in the reviewed material. That is not proof of absence. If exact paths or evidence are not returned, say so rather than citing guessed locations. Mark claims of app breakage as uncertain unless actual evidence establishes the relevant behavior.
