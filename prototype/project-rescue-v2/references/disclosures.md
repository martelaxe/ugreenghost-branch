# Development and third-party disclosure

The Project Rescue V2 workflow and Skill instructions were developed for the 2026 UGREEN AI NAS Hackathon. OpenAI Codex was used for research, authoring, local simulations and review. The installed UGREEN Uliya Skill Creation Tool and capability catalog were used as development references and for static checking; UGREEN supplies them under its own terms. This package contains no third-party executable libraries, SDKs, model weights or included datasets. The NAS runtime and model provider are external dependencies governed by their respective terms; model configuration and associated data flows must be verified by the user and platform. No claim is made that the underlying model runs locally or that archive data cannot leave the device.
