# Round 1 fallback outline — Project Rescue, for review only

**Status:** fallback recommendation after Readiness Delta STOP; not a final submission. Existing prototype: `prototype/project-rescue/SKILL.md`. It passed the official static checker on 2026-10-27, but actual UGREEN execution and safe no-overwrite behavior are unverified. Before any submission, address the disclosure requirement in a new copy, validate package and proposal, and confirm no collision-safe behavior is promised without evidence. Do not publish or submit automatically. Close competitor: Adobe Premiere Link Media. This outline is not a claim of unique technology or a guarantee of finalist selection.

1. **Skill:** Find a documented missing project file and offer one approved, source-preserving copy of a verified match.
2. **User/problem:** A creator or small team has a project referencing an absent file while copies may still support other work.
3. **Solution:** Compare actual project references with candidate file evidence and prepare a precise, non-overwriting recovery proposal.
4. **Flow:** Owner states goal and authorized scope; inspect; show evidence and exact copy; obtain owner and gateway approval; copy only if collision safety is enforceable; inspect source and destination afterward.
5. **Difference:** Cross-folder evidence and preservation of a shared source are the intended workflow; ordinary AI agents and application-specific relinking overlap, so no general superiority is claimed.
6. **NAS capabilities:** `file-agent` discovers, reads, hashes and, if safely supported and approved, copies; `document-agent` extracts actual project references.
7. **Technical approach:** Markdown parent delegates to registered experts and uses actual completed results. The core does not use scripts. It handles incomplete scope and stops on uncertain identity, collision, denial or unsupported approval.
8. **Status:** A prototype passed static validation. Local Python copied one fictional file and checked hashes; generic and Skill-guided agents both identified a candidate. No UGREEN agent or hardware action has run.
9. **Device plan:** Core: recover a hash-matching missing file into an empty authorized target and confirm both copies; protect a file referenced by another project. Edge: deny approval or present an occupied target and verify no write.
10. **Limits:** Unknown no-overwrite atomicity, approval resumption, source returns and readback; no complete dependency detection, guaranteed undo or proof an application opens. Model configuration determines data flows. Stop if safe copy cannot be established.

AI-development disclosure and applicable third-party component/source/license information must be reviewed and added to the eventual package/proposal. The official event currently requires the disclosure in SKILL.md or a directly linked Markdown reference. The user must make the final submission decision; this outline does not submit anything.
