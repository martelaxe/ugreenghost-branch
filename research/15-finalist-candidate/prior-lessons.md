# Lessons from prior experiments

- 01 found a plausible overlooked deposit; source evidence matters more than a dramatic claim.
- 05's generic baseline outperformed the overcomplicated harness in the small evaluation; an empty verifier discarded candidates, so extra stages can harm.
- 06 preserved candidate evidence and unknowns with deterministic local tests; it did not prove semantic intelligence or NAS execution.
- 08's Missing Piece and 09's Creative Salvage showed version, rights, source and missing-data complexity, while generic models recovered similar ideas; some citations were invalid.
- 10–11 showed credible impact-previews and generated artifacts but not a clear WOW beyond general AI, and no user/device validation.
- 12 demonstrated a real local safe-copy analogue, but UGREEN copy approval, no-overwrite and readback remain unverified; Adobe and generic agents overlap.
- 13's task artifacts were often as good with generic AI; adding a task record did not prove user value or persistent state.
- 14 found fresh agents can continue from saved Markdown; generic-with-record handled stale/missing cases similarly to the Skill. Its raw report links failed and one Skill-guided run misstated file count. The chosen STOP was for that standalone idea, not for all file review.

Common discipline: keep procedures concise, compare actual generic and frozen Skill outputs, preserve exact source identity, differentiate uncertainty from evidence of failure, measure physical mutations, do not claim hardware, universal monitoring, novelty or user preference without evidence.
