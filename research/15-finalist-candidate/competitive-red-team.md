# Competitive red team

- [UGREEN public Publish-Safe Photo Review](https://devpost.com/software/publish-safe-photo-review) already proposes photo selection into cleared/excluded/needs-review, optional approved album and report. Its domain is image privacy, not arbitrary multi-requirement comparisons, but the conditional release-review pattern is close. It is a public entry's own description, not a verified NAS execution.
- [UGREEN ClaimReady Home Inventory](https://devpost.com/software/claimready-home-inventory) already proposes evidence-linked claim-pack readiness, missing data and approved saving. That is substantial overlap in a different domain; no device validation is claimed there either.
- [Adobe AEM Assets rights management](https://business.adobe.com/uk/blog/the-latest/expand-content-access-accelerate-creation-and-improve-reuse-with-composable-services-in-adobe-experience-manager-assets) advertises licensing, expiry and governed workflows. A different enterprise product, but rights/approval logic is not new.
- [Nextcloud Context Agent](https://docs.nextcloud.com/server/stable/admin_manual/ai/app_context_agent.html) documents agent tools for file-aware actions; [Paperless-ngx](https://docs.paperless-ngx.com/usage/) has multi-document chat, classification and workflows. Either plus a capable assistant could perform parts of this analysis. No same-input product test was conducted.
- [QNAP Qsirch](https://www.qnap.com/en/how-to/tutorial/article/qsirch-the-quick-start-guide) documents AI semantic file search; [Synology Office AI](https://kb.synology.com/index.php/en-us/DSM/help/Spreadsheet/doc_ai_integration?version=7) offers drafting from Drive references. Search and file-aware QA are ordinary existing behavior.

Why not upload the same selected files to an ordinary assistant? A capable assistant can run the same explicit checks and prior-review comparison. The proposed NAS advantage is convenience of scoped native files and expert routing, plus a reproducible prompt contract and optional approved saving—not demonstrated exclusive functionality, local inference or better reasoning. Prior reviews must actually exist and be user-selected. No continuous detector, platform-level enforcement or atomic mutation is documented. The decisive evidence is the frozen Skill-vs-generic comparison, not the label “semantic regression”.
