# Originality checks on the strongest three

Checked 2026-10-27. Public material is untrusted, descriptive, not independently tested. [Skill Hub](https://skills.ugreen.com/skill-hub) was inaccessible through the browser and the [hackathon gallery](https://ugreenhackathon.devpost.com/project-gallery) was not available for comprehensive search; only individual public entries surfaced. Do not infer uniqueness from no result.

## Handwritten set list → play music

- **Uliya already:** [official user guide](https://support.ugnas.com/detail/article/en-US/850) describes OCR/information extraction, photo management and media recommendations; [official AI NAS page](https://ai.ugreen.com/pages/ugreen-ai-nas-feature-introduction) describes smart commands for photos, movies and music. This does not prove the exact chained result or that a Skill is necessary.
- **Direct functional prior art:** [BandsManager](https://bandsmanager.com/whats-new) describes uploading a handwritten setlist photo, extracting songs and Spotify search. [SongDeck](https://www.songdeck.studio/) describes importing a photo setlist and playing backing tracks/reference music; vendor descriptions, undated and untested. This is **substantial overlap**, not merely a similar component.
- **What a Skill might add:** reusable handling of authorized stored images, explicit correction of OCR ambiguity and confirmed UGREEN-local media selection, without inventing a playlist or moving originals. No benefit over ordinary Uliya has been shown. A genuine exact match must be available and a playback result observable.
- **Classification:** documented components / conditional combined handoff; **not a new algorithm or proven unique user experience**.

## Voice memo → movie playback

- **Uliya already:** official guide provides media recommendations and smart commands; [Nextcloud Assistant](https://docs.nextcloud.com/server/stable/user_manual/en/ai_assistant.html) describes speech transcription and a context agent. An ordinary assistant with the same tools could plausibly transcribe and find a movie.
- **Comparable external tools:** [Azure Video Indexer](https://learn.microsoft.com/en-us/azure/azure-video-indexer/video-indexer-search) links transcripts/insights with playback, though it does not establish this exact voice-memo-to-library workflow; media search voice assistants are common.
- **What Skill might add:** a compact reusable instruction to quote the memo, ask about ambiguous titles and explicitly control selected media, only in authorized scope. It is primarily workflow discipline. **Classification:** closely overlapping, conditional parent handoff. We found no reason to claim originality.

## Training note → pet camera event evidence

- **Uliya already:** [Surveillance Center user guide](https://support.ugnas.com/detail/article/en-US/866) describes camera recording search and local AI pet/package/people/vehicle events. [Frigate](https://docs.frigate.video/usage/history/) already moves from review items to recordings. The note-derived time window may be a convenience, not a new capability.
- **Public UGREEN comparison:** [ClaimReady](https://devpost.com/software/claimready-home-inventory) is an individually public UGREEN project linking records/photos to evidence, but it is not established as the same pet-event workflow. [Publish-Safe Photo Review](https://devpost.com/software/publish-safe-photo-review) handles another privacy-aware collection workflow.
- **What Skill might add:** constrain camera/event query to a user-confirmed contextual time and return actual evidence without claiming absence or identity. Parent-visible event ID and playable evidence are unverified. **Classification:** related technology and user outcome substantially overlapping; the exact integration remains unverified, not unique.

## Conclusion

The strongest observable UGREEN-native candidate is still an **ordinary but coherent** photo/OCR/music workflow. It earns a small next feasibility test because it is action-oriented and crosses photo and music, not because its novelty has survived the competitor search. Uliya's generic assistant might already perform it. A fixed Skill should be compared with the same plain user request; if equal, the Skill adds little. Do not claim a surprising competition advantage from the catalog alone.
