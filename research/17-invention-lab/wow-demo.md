# A 60-second What-If Exhibit

**0–10 seconds — Before.** A three-panel event display has an arrival, a workshop and an ending. [Local baseline](../../experiments/17-invention-lab/probes/bridge/outputs/baseline.png) uses two red assets and one green. These are fictional vector icons with authored labels, not real event photographs.

**10–20 — Unusual request.** “The venue cannot print red. Keep the same three moments; if you cannot support a replacement, leave a hole.”

**20–35 — Unexpected behavior.** Re-run the local projection with red excluded. The [display](../../experiments/17-invention-lab/probes/bridge/outputs/no-red.png) changes the first two source assets to blue alternatives and keeps the ending. The original five SVG files retain their hashes.

**35–45 — A stronger challenge.** Also exclude blue. The [third output](../../experiments/17-invention-lab/probes/bridge/outputs/no-red-or-blue.png) leaves two clearly empty roles rather than inventing substitutes. This is the important counterexample: the system is allowed to fail visibly.

**45–60 — What happened and what did not.** The observed changes are three newly generated local SVG artifacts, not modifications to originals and not a NAS album. Selection was deterministic Python using manually authored role/color labels; no AI interpreted the images and no real user requested it. It is more than a prompt in the local prototype because a small program materializes different artifacts and tracks selection. However a user could manually swap assets in an editor; photo book layouts, dependency engines, UGREEN photo Skills and generic AI cover much of the workflow. The larger vision is a real, source-aware projection that reacts to changed evidence. Today's plausible NAS fragment is an on-demand reasoned selection and, only after approval and confirmed runtime support, a new album; it may not retain order or create a visual sheet. Never present the local animation as actual UGREEN runtime.
