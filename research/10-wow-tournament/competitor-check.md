# Narrow competitor check for the four finalists

Live sources checked 2026-10-26. These are product documentation or developer claims, not independently tested product performance. “Not found” is not proof of global novelty; all four experiences can be attempted with a generic AI assistant given the same files.

| Finalist | Closest verified source and overlap | What could still be distinctive / limitation |
|---|---|---|
| Digital Archaeologist | [invoice-agent](https://github.com/superintelligenceco/invoice-agent) describes matching invoices, purchase orders and receipts, duplicate checking and review/reject reasons. [ChatGPT file analysis](https://help.openai.com/en/articles/8437071-data-analysis-with-chatgpt) describes uploaded-file analysis. Experiment 01's generic Codex already found a potential deposit discrepancy. | A proposed consumer-facing, bounded, source-linked inquiry draft over an existing NAS archive could reduce preparation; no evidence this is exclusive or more effective. Not every competitor's exact deposit-refund workflow was tested. |
| Pocket Exhibit / Archive Alchemy | [Canva Magic Write](https://www.canva.com/help/about-magic-write/) documents text generation from prompts or existing design text; [Adobe Experience Manager Assets](https://business.adobe.com/products/experience-manager/assets/digital-rights-management.html) advertises finding reusable assets and managing rights. Experiment 09's generic and specialized agents created similar creative proposals. | A six-panel text artifact built from user's existing notes with visibly separated facts, invented lines and rights gaps could offer convenience; existing tools or generic agents may do the same. Text panels are not a rendered/printed zine. |
| Fork in the Budget | [Microsoft Excel What-If Analysis](https://support.microsoft.com/en-us/excel/introduction-to-what-if-analysis) explicitly supports scenarios and scenario summary reports. [Copilot in Excel](https://support.microsoft.com/en-gb/excel/copilot/frequently-asked-questions-about-copilot-in-excel) documents multistep workbook analysis. | NAS notes could supply the conflicting source terms and the Skill could lay out decisions in chat. Generic Codex already made conditional reports in Experiment 08; numerical what-if analysis is not novel. |
| Archive Quest | [Escaply](https://www.escaply.com/en) advertises creating games, stories or escape rooms from users' teaching material; [docs-to-quiz](https://docs2quiz.github.io/getting-started/introduction/) documents generating source-cited questions from uploaded documents. [Family Game Night](https://familygamenight.app/) advertises AI-personalized games using family photos and context. | This is a new direction for **our project**, not an invention of source-based escape rooms. A private, user-scoped personal-archive quest with cited solutions may be a different target use; it is not established that others cannot do it or that all inference is private/local. Photo support and live interactive state on UGREEN remain unverified. |

Evidence gaps: product listings and features change, Escaply's exact capability to use a personal NAS in place was not tested, and UGREEN Skills Hub and the contest's unpublished gallery were not exhaustively inspected. No conclusions about price, deployment security or comparative performance are supported by this review.
