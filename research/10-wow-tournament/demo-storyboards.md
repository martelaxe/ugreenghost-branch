# Four 90-second reveal storyboards

All demonstrations below are **plans** for a possible UGREEN run. The only executed portions are the four fresh local Codex investigations and their raw text outputs under [outputs](../../experiments/10-wow-tournament/outputs/); no actual NAS UI, expert calls, media generation, approvals, or interactive reply handling were recorded. In any eventual demo, use the actual authorized folder and expert outputs; do not simulate progress or pass local Codex output off as NAS footage.

## 1. Digital Archaeologist — a potential $420 discrepancy

- **0–10 s — problem and request:** A creator says “Investigate my archive for an overlooked financial issue and draft a message I can use.” Viewer sees an authorized event-record folder.
- **10–30 s — investigation:** Planned NAS view: file/document/knowledge experts inspect the booking, payment and closing record. Actual local Codex inspected the fictional text files; NAS handoffs have not run.
- **30–60 s — reveal:** “Possible $420 unapplied or unreturned deposit.” The user sees deposit $420, final bill $900 and deposit applied $0; no assertion a refund is definitely owed.
- **60–90 s — useful result/evidence:** A reviewable message asks the venue to clarify the deposit with HR-241 sources and acknowledges a later refund may exist. Actual local artifact: [raw response](../../experiments/10-wow-tournament/outputs/archaeologist/raw-response.md). No message was sent.

## 2. Pocket Exhibit — a six-panel text zine

- **0–10 s:** User types “Turn my old projects into a six-panel educational zine using materials I can reuse.” Viewer sees old notes in two folders.
- **10–30 s:** Planned NAS view: source discovery and permission review; actual local Codex read the text fixture.
- **30–60 s:** Reveal the finished six-panel text: a river note, an abandoned three-wave paper activity, and labeled new poetry. This is copy-ready **text**, not a layout, PDF, photo or printed zine.
- **60–90 s:** Show the source-backed free educational reuse grant and excluded photo set; prompt the user to verify printer access. Actual local artifact: [raw response](../../experiments/10-wow-tournament/outputs/alchemy/raw-response.md).

## 3. Fork in the Budget — two concrete futures

- **0–10 s:** User types “Show me the two possible budgets before I decide which quote to accept.” Viewer sees a small event folder and an unresolved revision.
- **10–30 s:** Planned NAS view: locate and reconcile the quotes and table estimate; actual local Codex reviewed the fictional records.
- **30–60 s:** Two drafts appear: $200, leaving $40 of headroom, versus $280, $40 above the $240 ceiling. The later quote is unapproved.
- **60–90 s:** Show the quote, policy and estimate sources; user can compare outcomes and decide. No actual follow-up approval has been executed. Actual local artifact: [raw response](../../experiments/10-wow-tournament/outputs/fork/raw-response.md).

## 4. Archive Quest — a static mystery from the files

- **0–10 s:** User types “Turn my workshop archive into a playable mystery for my family.” Viewer sees a folder of old fictional records.
- **10–30 s:** Planned NAS view: inspect selected notes and extract clues. Actual local Codex read the archive; no NAS call or secret answer-checking service occurred.
- **30–60 s:** Show the ticket, diary, stock card and activity sheet as a text puzzle. The player matches a year, then calculates the remaining sheets.
- **60–90 s:** Reveal the spoiler answer `BLUE 12` and file paths. The existing local output includes both puzzle and spoiler in one response; the demonstration would have to hide the answer manually until reveal. Actual local artifact: [raw response](../../experiments/10-wow-tournament/outputs/quest/raw-response.md). Two displayed quotations are slightly altered; repair attribution before claiming evidence-grade accuracy.

The Quest is deliberately new to our project but ordinary source-based escape rooms already exist. It has not been independently played or rated. A real NAS chat's spoiler visibility and ability to accept/check a later reply are unknown.
