# Uliya feasibility: product capabilities versus delegable operations

Research date: 27 October 2026. Authoritative local input: installed Uliya skill kit catalog v2.0.0, generated 2026-09-01, SHA-256 `c927fd8e233696cd152baf98468368912c13c08aabeac353f0ee95c46c0428e6`; its orchestration, safety and completion references. Normalized record and original pointers: [operation catalog](../ugreen-capabilities/02-operation-catalog.json), [composition graph](../ugreen-capabilities/04-composition-graph.md). 78 listed operations, nine CLIs, six registered experts. This is the installed catalog, not a claim that all deployed versions implement every entry. The parent delegates to registered experts; it must not directly run specialist CLIs. Concrete scope and inputs come from the user and actual upstream results.

**Interpretation of status:** DOCUMENTED = the catalog describes an operation, not that we observed it on a NAS. LOCALLY SIMULATED = an earlier experiment with a local filesystem, never UGREEN execution. UNKNOWN = a required behavior or contract is unspecified. UNSUPPORTED HERE = no corresponding operation found in the inspected catalog, not a proof no other UGOS interface exists.

## Completion and safety

A read-operation approval classification of `none` does not confer user consent or access to a private folder. For modifications respect user scope, explicit approval and the documented gateway/workflow; wait for actual success, fail, cancellation or approval-pending states. Do not fabricate a per-file result or assume asking an expert means it executed. Where a child does not return its observations, report unknown. No automatic approval-resume mechanism or atomic copy guarantee was independently verified. This audit did not access real NAS data or execute expert agents.

**Conclusion:** A read-only, bounded comparison or source-grounded explanation is plausible on paper. User-facing restoration, app-consistent disaster recovery, live health monitoring and execution guarantees are not established from this catalog. This finding concerns the Skill surface, not the whole UGOS product.
