# Published Skills and overlap

Research date: 27 October 2026. This draws from the [live marketplace audit](../ugreen-skillhub-real-marketplace-audit.md), which read all 30 UGREEN-source detail pages and a selected sample of GitHub-source pages and 28 actual `SKILL.md` files. No Skill was installed or run. **First-party descriptions are publisher claims:** their actual `SKILL.md` contents were not publicly obtained in that audit. GitHub packages are different agents and are not evidence of Uliya compatibility. This is a snapshot, not exhaustive coverage of GitHub's catalog.

| Skill and owner | Advertised or inspected behavior | Product relevance and limitation |
|---|---|---|
| UGREEN [File organization](https://skills.ugreen.com/us/skills/144) | Plans contextual organization, preview, confirmation and undo as described in page. | Close competitor for minimum-change organizer; no proof of our precise optimization objective, per-file guarantees or working undo. |
| UGREEN [File deduplication](https://skills.ugreen.com/us/skills/131) | Match by name/content, retention suggestion, user confirmation and recycle-bin cleanup. | Substantial overlap with duplicate cleanup; do not infer atomic deletion or exact hash coverage. |
| UGREEN [File cleanup](https://skills.ugreen.com/us/skills/132) | Identify temporary, old or large items and ask before processing. | Existing broad cleanup flow; not application-aware database or volume repair. |
| UGREEN [File management](https://skills.ugreen.com/us/skills/147) | Add, view, move, copy and create folders. | Action component of Project Rescue; listing does not establish contextual identity resolution or atomic safe copy. |
| UGREEN [File search](https://skills.ugreen.com/us/skills/146) | Natural-language search using file properties; says it does not move/delete/rename. | Baseline for discovery; does not establish multi-file recovery reasoning. |
| UGREEN [Cross-document retrieval & summarization](https://skills.ugreen.com/us/skills/33) | Search, compare, synthesize, flag conflicts and cite sources. | Close to Experiments 01–06 and app-configuration explanations; no demonstrated surprise engine or exhaustive coverage contract. |
| UGREEN [UGREEN NAS official knowledge Q&A](https://skills.ugreen.com/us/skills/141) | Answer product-usage questions with official knowledge references. | Support and checklist prompts already have an official home; not proof of live system diagnosis. |
| UGREEN [Photo timeline](https://skills.ugreen.com/us/skills/143) | Find photos by time and other context. | Overlap with temporal/personal archive ideas; not a historical record of the state of an entire filesystem. |
| UGREEN [Event query](https://skills.ugreen.com/us/skills/138), [Event evidence](https://skills.ugreen.com/us/skills/140) | Query time/zone events, present event cards, extract event evidence, per descriptions. | Surveillance events and export already exist; listing is not evidence of complete continuous footage. |
| GitHub-source [Jikji Local File Discovery Skill](https://skills.ugreen.com/us/skills/241) | Inspected instructions use Rust-based index plus stop/retry/bounded-fallback procedure. | A real workflow contract rather than a one-line prompt; requires a separate program/index and does not establish Uliya support. |
| GitHub-source [xsm-bf](https://skills.ugreen.com/us/skills/406) | Inspected instructions plan and verify workbench backup/restore with PowerShell. | Relevant to Rebuild Kit, but script-based, not a documented NAS expert. |
| GitHub-source [HA Git Backup](https://skills.ugreen.com/us/skills/1024) | Inspected instructions separate config Git history and encrypted full backups, with restore checks. | Direct prior art for app continuity; uses shell, secrets and external infrastructure rather than a Markdown-only Uliya Skill. |
| GitHub-source [Engramory](https://skills.ugreen.com/us/skills/1041) | Inspected file-backed memory/index and recall rules. | Overlap with continuity/handoff; actual UGREEN file access and persistence remain untested. |
| GitHub-source [Media Library Organizer](https://skills.ugreen.com/us/skills/1210) | Inspected instructions cover media scanning, renaming and TMDB-based comparison through shell/scripts and external data. | Strong media-organization prior art; not a native UGREEN expert, nor proof all its actions are approval-gated. |

The original [audit's source captures](../ugreen-skillhub-audit-evidence/) preserve actual third-party Skill files where publicly accessible. A marketplace badge or listing is not proof of a tool's operation, source quality or competition eligibility. **Version Explorer, Sync & Backup and iDX organization are native product functions, not Skill listings.**

Useful design lesson: publisher examples range from basic question-answering to staged action procedures. A workflow becomes meaningful when it changes user outcomes with verifiable state transitions and failure handling; a multi-agent diagram alone does not establish innovation or proven quality.
