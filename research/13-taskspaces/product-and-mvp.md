# Vision and bounded MVP

**Future vision — speculative:** an AI NAS could connect a person's goal to relevant authorized information, reusable decisions and verified actions across applications. It might eventually remember past activities, adapt to user preferences and coordinate work over time. This experiment provides no persistent memory, background jobs, custom interface, autonomous app integration, self-modifying Skills or graph.

**MVP — Decision-Ready Task Capsule:** “Prepare a usable event invitation and handoff from the selected archive, and show me what still needs my decision.” Bounded authorized folder, `file-agent` discovery + `document-agent` source extraction, parent returns a source-linked usable text package, and optionally `knowledge-agent` saves the approved text via documented workflow approval. Original files remain untouched. A virtual reference list is not a physical workspace. If save approval or readback does not work, return the text in chat and say it was not saved; never present a simulated write as a device operation.

Proposed 90-second demonstration: choose fictional archive → state goal → see an actual invitation with confirmed date and venue → see outdated source and internal-only photo explicitly held → user chooses approved artwork and confirms missing accessibility information → optionally approve a save, then inspect actual returned path and contents. Existing local tests produce text, not a NAS screen, album, completed event or public release. Judge what was actually returned; external decision and dissemination are never assumed.
