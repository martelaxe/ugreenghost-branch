# Seven task-oriented experiences

These are hypotheses, not seven capabilities already delivered or unique inventions. Each uses actual authorized sources and no saved instruction becomes authority merely because it is found in the archive.

| Identity | Natural request and inputs | Transformation, benefit and 90-second reveal | Agents and boundaries / closest comparison |
|---|---|---|---|
| Intent Workspace | “Help me prepare for the design review” over notes, drafts and checklist references. | A virtual linked list plus usable review brief and outstanding decisions; reveal that a missing checklist and old instruction differ. A virtual grouping does not move files. | `file-agent`, `document-agent`; optional `knowledge-agent` save-text with approval. Source coverage/returns unknown. Nextcloud assistant already contextualizes files. |
| Goal-Driven Organizer | “Group records for my accountant” over invoices, receipts and bank text. | A purpose-specific proposed grouping, duplicate/version ambiguity and no unauthorized moves; optionally one approved operation only if safe. Reveal same bytes versus a revised amount. | file/document; cpmv or tags separately approved if used. No tax conclusions; no atomic no-overwrite guarantee. Paperless already classifies and tags. |
| Task Capsule | “Prepare a reusable review package” with notes and approved references. | One compact linked artifact: result, evidence, decisions and safe next action; only save if requested and approved. Reveal a usable review sheet, not another folder. | file/document; knowledge-agent `save-text` optional. Save path, collision and resume unverified; no automatic task memory. Nextcloud and generic agents can also generate documents. |
| AI Storage Operator | “Fix this one missing project asset” with manifest and matching copy. | Verify evidence, seek exact approval, copy a single source and inspect result; reveal a path restored while a shared original stays. | file/document; cpmv gateway; atomic no-overwrite unknown, stop if unassured. Adobe relink already handles related workflows. |
| Task-Aware Knowledge | “What should I know to resume this handoff?” over prior notes, instructions and drafts. | Current versus superseded sources and unresolved questions in a source-linked answer. No execution of historical prompts. | file/document; limited by source coverage and model interpretation. Nextcloud and Paperless support contextual questions. |
| Decision Gate Pack (new) | “Prepare the event invitation and handoff for review” over event text, a permission note and timetable. | A ready-to-edit invite plus short handoff; the surprise is the conflict between an old date and current venue, and an unapproved photo. User decides public use; output is not sent. | file/document; optional knowledge save. Only documented text sources tested; actual media/permissions capabilities unknown. Normal agent can generate a similar pack; Nextcloud is close. |
| Cross-Task Evidence Bridge (new) | “Prepare one factual status sheet for both the client and accountant” using project notes and invoices. | A single concise source-linked sheet with an explicit distinction between invoiced, paid and disputed. Reveal a dispute hidden beside a paid invoice, avoiding double counting. | file/document; optional save. Financial interpretation is limited to documented facts; no advice. Paperless chat and generic Codex overlap substantially. |

A portable decision-ready capsule is the most coherent selected identity for testing because it yields a concrete reusable text artifact while keeping setup small. This is a provisional product judgment: the broad operating layer and proactive persistence remain speculative, and the local comparison may show ordinary generic behavior.
