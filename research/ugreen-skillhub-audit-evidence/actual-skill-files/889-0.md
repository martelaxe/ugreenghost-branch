# C盘安全清理与迁移规划助手 Skill

## 目标

本 Skill 用于帮助 Windows 用户安全分析 C 盘空间占用，并生成清理或迁移规划。

它的核心目标不是「一键删除更多文件」，而是：

> 先识别 C 盘内容，再分类风险，生成用户可读报告，用户确认后再执行清理或迁移。

v1.5 起，`Classify` 会同时生成 TXT、JSON 和 HTML 报告，并加入释放空间预估、C盘健康评分和应用级迁移指南。

---

## 适用场景

当用户提出以下需求时，可以使用本 Skill：

* C 盘空间不足
* 想知道 C 盘被什么占满
* 想清理 C 盘但担心误删文件
* 想把下载、桌面、图片、视频、微信文件迁移到 D/E/F 盘
* 想分析每个磁盘剩余空间
* 想识别大文件或重复文件
* 想整理开发环境缓存，如 npm、pip、conda、Docker、WSL
* 想生成一份清理和迁移规划，而不是直接执行

---

## 不适用场景

不要用本 Skill 做以下事情：

* 删除系统核心文件
* 移动 Windows 系统目录
* 移动 Program Files 中的软件安装目录
* 强制删除被占用文件
* 强制结束用户进程
* 直接移动 WSL2 或 Docker 虚拟磁盘
* 直接修改注册表启用长路径
* 在用户未确认前执行真实清理或迁移
* 删除用户文档、照片、视频、桌面资料

## 推荐工作流

### 第一步：向导或分类识别

面向普通用户，默认首选：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_c_drive.ps1 -Mode Wizard
```

向导会让用户选择：

```text
1. 只看看 C 盘被什么占满
2. 清理安全缓存（只做 DryRun 预览）
3. 把大文件迁移到其他盘（只生成规划）
4. 查找重复大文件
5. 生成完整报告给 AI 分析
```

如果需要非交互式执行，使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_c_drive.ps1 -Mode Classify
```

该模式只生成报告，不删除、不移动、不修改系统。

输出：

```text
c_drive_classified_review_plan.txt
c_drive_classified_review_plan.json
c_drive_report.html
```

AI 应优先读取 `c_drive_classified_review_plan.json` 做结构化分析；需要面向用户解释时，再参考 TXT 或 HTML 报告。

---

### 第二步：清理预览

如果用户想清理缓存，应先运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_c_drive.ps1 -Mode Clean -DryRun
```

只有用户确认后，才建议运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_c_drive.ps1 -Mode Clean
```

---

### 第三步：迁移规划

如果用户想移动 C 盘内容到其他盘，应先生成迁移规划：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_c_drive.ps1 -Mode PlanMove -TargetDrive D:\
```

输出：

```text
c_drive_move_plan.txt
c_drive_safe_move_preview.ps1
```

不要直接建议用户剪切系统目录或软件目录。

---

## 风险分类规则

### 1. 可直接清理

可归入低风险清理项：

```text
用户 Temp 目录
Windows Temp 目录
浏览器缓存
崩溃日志
回收站
Windows 更新下载缓存
npm 缓存
pip 缓存
部分 conda 缓存
```

注意：即使是低风险项，也应先 DryRun。

---

### 2. 适合迁移

可建议迁移，但不应直接删除：

```text
下载目录
桌面大文件
视频素材
图片素材
安装包
压缩包
导出文件
项目数据集
旧资料
```

推荐流程：

```text
复制到目标盘
确认能打开
修改软件默认保存路径
再删除 C 盘原文件
```

---

### 3. 先改设置再迁移

以下内容不建议直接剪切，需要先修改软件设置：

```text
微信文件
QQ 文件
OneDrive 同步目录
npm 全局包路径
pip 缓存路径
conda 环境目录
Docker 数据目录
WSL2 虚拟磁盘
```

AI 应提醒用户：先在软件或工具内部修改路径，再迁移历史文件。

---

### 4. 不要动

以下内容必须标记为高风险，不建议移动或删除：

```text
C:\Windows
C:\Program Files
C:\Program Files (x86)
C:\ProgramData
C:\System Volume Information
C:\Recovery
C:\Windows\System32
C:\Windows\WinSxS
pagefile.sys
hiberfil.sys
swapfile.sys
ext4.vhdx
Docker 虚拟磁盘
已安装软件主目录
```

## 工程安全要求

脚本应遵循以下要求：

1. 只读模式不请求管理员权限。
2. 需要管理员权限的模式应检测权限并提示，而不是直接失败。
3. 无权限访问的目录应跳过并写入日志。
4. 被占用文件应提示用户关闭相关程序，不强制关闭。
5. 符号链接、Junction、ReparsePoint 应默认跳过。
6. 长路径应识别并报告，不默认修改注册表。
7. 所有清理和迁移动作应记录日志。
8. 所有迁移操作应先生成预览脚本，不默认执行。
9. 删除动作只作用于明确配置的低风险缓存目录。
10. 不应删除用户个人文件夹中的文档、图片、视频、桌面内容。
11. `protectedUserPaths` 中的路径只扫描，不清理、不迁移、不生成删除建议。

---

## 回答用户时的语气

回答用户时应强调：

* 先分析，不直接删
* 先生成报告，再确认
* 不确定的内容不要动
* 重要文件先备份
* 微信、QQ、Docker、WSL、conda 需要特殊处理
* C 盘清理的目标不是删得多，而是删得准、删得安全

---

## 用户给出报告后如何解读

当用户提供 `c_drive_classified_review_plan.txt` 或 `c_drive_move_plan.txt` 内容时，AI 应按以下结构回答：

1. 总体判断：C 盘主要被什么占用。
2. 可立即清理项：低风险缓存。
3. 建议迁移项：用户文件和大文件。
4. 谨慎处理项：微信、QQ、OneDrive、Docker、WSL、conda。
5. 不要动项：系统目录和虚拟磁盘。
6. 推荐下一步命令。

不要让用户直接删除高风险目录。

当用户提供 `c_drive_classified_review_plan.json` 时，AI 应优先读取：

1. `summary`：C 盘容量、剩余比例、风险等级。
2. `health`：健康评分、主要问题、推荐优先级。
3. `estimates`：预计可清理、可迁移、需改设置后处理的空间。
4. `categories.safe_to_clean`：可 DryRun 后清理的缓存。
5. `categories.safe_to_move`：可复制到其他盘后核对的用户目录。
6. `categories.change_settings_first`：微信、QQ、OneDrive、conda 等需先改设置的内容。
7. `categories.do_not_touch`：系统目录和虚拟磁盘，不建议移动或删除。

## 配置文件

清理规则、扫描目录、排除项、进程提示等定义在：

```text
config/safe_clean_config.json
```

优先修改配置文件，而不是硬编码到脚本中。

如需保护论文、科研数据、重要照片或项目目录，可配置：

```json
"protectedUserPaths": [
  "%USERPROFILE%\\Desktop\\论文",
  "%USERPROFILE%\\Documents\\科研数据"
]
```
