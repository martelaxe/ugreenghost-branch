# Hypothesis: reveal an evidentiary boundary, not a person's mind

A user asks a specific historical question. At a declared cutoff the system constructs a **then** view using only records whose availability within an identified archive can be supported; it withholds later records and quarantines uncertain availability. A fresh investigator interprets this bounded record. A separate retrospective investigator examines the fuller archive and identifies which claims were retained, contradicted or still unproven. A reveal presents the actual later evidence beside the earlier interpretation. The mechanism is temporal evidence admission, two independent reasoning passes and claim-level comparison—not predicting a past person's thoughts.

It differs from a chronological list only if the cutoff actually controls what goes into the historical analysis and the reveal connects a specific later source to a specific earlier inference. It differs from a standard file version view only if provenance allows availability to be assessed, rather than assuming a modification time establishes historical knowledge. It does **not** differ fundamentally from a trustworthy point-in-time database plus AI, a careful retrospective chatbot with explicit provenance, or a documentary that does the same work. A visual reveal alone is presentation, not an invention.

The research prototype will physically isolate a fictional THEN workspace, check its file hashes against a fictional snapshot inventory, and treat backdated content and unknown receipt as separate from verified availability. This protects the exercise from direct access to deliberately withheld fixture files, not from all network/model-memory leakage or historical uncertainty. Fictional snapshot attestation is fixture evidence, not proof of any real event or decision-maker's access. Later records may overturn a claim but cannot prove that the earlier decision was irrational or a site was safe. If the generic agent using the same records produces the same explanation, or the reveal is merely a scripted example, the novelty claim is weak.
