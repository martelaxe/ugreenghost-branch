# Decision gates

**A — Technical credibility: CONDITIONAL.** Agent ownership, catalog actions and the permission/state boundaries are documented; the static checker passes. The Skill stops if safe atomic no-overwrite, exact path semantics, owner consent, gateway completion or post-action verification cannot be established. No confirmed UGREEN implementation guarantees the critical no-overwrite property. A finalist execution path is plausible but unproved, and may stay proposal-only if support is absent. Precheck plus `overwrite=false` is not enough.

**B — Generality: LIMITED PASS for local planning.** The same frozen instructions identified a creative asset and a business record from contextual evidence without an expected checksum supplied, and abstained in one ambiguous case. Both were synthetic, author-constructed, one trial per condition. The Skill's two coverage-count errors and nonportable links prevent an unqualified pass.

**C — Creative differentiation: NOT DEMONSTRATED.** Both competent generic Codex and specialized Skill recovered the same inference and handled the negatives. User benefit is plausible; the source-preserving copy is tangible locally, but no users have experienced it and ordinary tools overlap. Simulated judges gave innovation 7–9/25 normalized; not real judging. A serious practical entry is plausible, but we cannot credibly promise a strong Most Creative contender.

**Decision:** retain Project Rescue as a **conditional practical Round 1 review candidate**, not a proven differentiated or hardware-ready solution. Prepare the requested review-only package because Round 1 does not require NAS execution. The decisive next test is an authoritative UGREEN answer or real disposable-device test on exact `cpmv` destination interpretation, atomic collision behavior, gateway approval/resumption, parent result propagation and independent readback. If any safety guarantee remains absent, stop at proposal; do not stage a fake recovery.
