# Current state: Project Rescue

Experiment 12 produced a Markdown Skill using file-agent and document-agent, and a local fictional filesystem demonstration. A Python adapter, with synthetic owner and gateway approvals, copied one text file using exclusive creation and verified source and destination hashes. This was not an UGREEN operation or an actual owner approval. Its fixture included the expected SHA-256, making source selection unusually easy. See [the experiment 12 decision](../../docs/experiment-12-self-healing-archive-decision.md) and [local result](../../experiments/12-self-healing-archive/local-demo/before-after.md).

The original Skill promises scoped discovery, one evidence-backed approved copy, and independent readback if safe no-overwrite can be enforced. Its official checker passed; actual gateway approval, destination semantics, atomic no-overwrite, result propagation and readback remain unknown. File-agent and document-agent own the corresponding documented capabilities; a parent cannot directly call their CLIs. This is a conditional workflow, not demonstrated device operation. The retained [capability audit](../12-self-healing-archive/action-capability-audit.md) and [MVP results](../../experiments/12-self-healing-archive/mvp-results.md) describe the evidence.

Prior experiments constrain our claims: Experiment 05 lost promising candidates when a successfully called verifier returned an empty findings list; its internal reason is unknown, and an empty result is not disproof. Experiment 09's tiny generic comparison had a ceiling effect and invalid saved links; it did not establish an advantage. Experiments 13–14 found generic agents could use the same contextual handoff, with coverage-count and citation failures. Experiment 15 rejected its main candidate for similar generic parity and left Project Rescue as an unproven fallback. None demonstrates a general specialized-Skill advantage or real customer demand.

The old workflow is potentially useful but ordinary: application relinking, saved versions, generic agents and search already solve overlapping problems. This test removes the supplied checksum, adds competing versions, and asks whether multi-file identity reasoning and source preservation create a meaningful experience. They remain hypotheses pending independent testing and actual NAS behavior.
