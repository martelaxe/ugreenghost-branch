# Lessons carried forward

- 01: A model noticed an apparent $540 deposit discrepancy in a fictional archive; a compelling result still depends on actual sources and scope.
- 05: Generic reasoning exceeded the specialized harness on that small setup; verification sometimes discarded useful candidates. More instructions or agents are not automatically better.
- 06: Preserve candidates and their evidence; an empty verifier is failure/unknown, not refutation. Regression results demonstrate state handling, not general intelligence.
- 08: A missing search result is not proof an item does not exist. A real task and scope are more meaningful than generic search.
- 09: Creative Salvage's small model-judged comparisons and unusable temporary citations do not establish user value. Rights and source identity must survive handoffs.
- 10: Interesting demos can fail on exact quotations or user appeal; user delight remains unmeasured.
- 11: Impact Rehearsal identified two references, as did generic Codex. The static pass did not prove device execution; temporary paths were not portable citations. Source coverage and permissions remained uncertain. Rebuild Kit was a text artifact fallback, not a storage operation.

12 therefore makes one observable, bounded fixture change, keeps all originals, records approval as simulated, independently hashes before/after, and stops if actual device behavior cannot support a no-overwrite copy. A complete dependency graph, automatic undo or superior model intelligence is not claimed.
