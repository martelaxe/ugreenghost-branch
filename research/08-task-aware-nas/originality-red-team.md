# Originality red team

## Creative Salvage

- **Skeptical user:** “Why would I want ideas from abandoned material?” A searchable asset list already helps. Only proceed if actual creators prefer at least one concrete output and can trace it to files they can use.
- **Skeptical engineer:** “This is a prompt over notes.” Correct as currently designed: documented experts provide access but no novel algorithm or proof of quality. Test identical inputs/model/budget versus a strong generic prompt and measure the human's decision, not the aesthetic of a name.
- **Skeptical judge:** “A rights-aware DAM and an AI brainstorm already exist.” [Adobe Experience Manager Assets](https://business.adobe.com/products/experience-manager/assets/digital-rights-management.html) advertises AI-assisted asset reuse and rights management; generic assistants also overlap. The proposed outcome is an actionable alternate pitch constrained by sourced rights; no close match found in this limited review is not proof it is new.
- **Risk / redesign:** Never infer permission, identity or a safe asset from absent evidence. Present idea and blocked asset separately, suggest a genuinely independently supported alternative, and allow user review. A three-minute fictional demo depends on the underlying returned citations. Real device and creator testing could eliminate this concept.

## Knowledge Succession Rehearsal

- **User:** “Why not read the handoff?” A second person may discover an instruction they cannot use. This remains a hypothesis until real novice testing.
- **Engineer:** “A generic assistant writes exercises.” Yes. Product value, if any, is the rigor of a reusable source-linked practice workflow and native authorized access; neither has an established efficiency advantage.
- **Judge:** “Digital legacy products already transfer access.” [OneDrive](https://support.microsoft.com/en-gb/onedrive/preserve-your-digital-legacy-with-onedrive) addresses legacy access; a rehearsal tests usability, a different proposed result. No proof of global novelty.
- **Risk / redesign:** Do not certify recoverability or retrieve credentials. Ask a concrete low-risk task and mark the unsupported steps. In a one-day hardware window this text-only path is the least multimodal of the finalists.

## Fork & Finish

- **User:** “I can compare two files.” The conditional result is only worthwhile if it makes a consequential choice clearer or saves effort. Our small benchmark does not measure time or user value.
- **Engineer:** “A generic prompt can do this.” **Demonstrated:** generic G computed both correct conditional totals in case C, and the specialized S produced invalid source links. Claimed reasoning superiority is unsupported.
- **Judge:** “Scenario analysis is common.” [Excel Copilot](https://support.microsoft.com/en-us/excel/get-direct-answers-to-your-data-analysis-questions) supports follow-up analysis and a generic assistant readily produces alternatives. A creative name and side-by-side table are not invention.
- **Risk / redesign:** Use the interaction as a supporting pattern in a more distinctive task. Retain a single-turn conditional report as fallback if real multi-turn decision persistence is unsupported.

## Distinctions

A memorable name is **not** an innovation. A staged demo is **not** user value. A source-backed pitch that changes a real creator's next choice could be a differentiated **outcome**, if shown against meaningful alternatives. No genuinely differentiated **technical mechanism** has been established. UGREEN integration could reduce friction in an existing archive, but a generic assistant can also work on a mounted NAS folder. The actual user benefit and expert-output reliability remain untested.
