# Where might the invention lie?

We distinguish an advertised interaction from a verified mechanism. **No genuinely differentiated technical mechanism has been demonstrated.** The strongest plausible opportunity is an **output and interaction**: a creator sees two source-linked directions and how a real restriction changes which one can proceed. It may be memorable, but a generic assistant could produce the same thing; NAS access and a reusable contract are hypotheses about convenience, not proof of advantage.

| Layer | Potential benefit | Evidence / hard limit | Assessment |
|---|---|---|---|
| A. Better reasoning | Fewer false gaps and safer choices | Generic performed the four core cases; S scored lower on one run and broke links. | No improvement demonstrated. |
| B. Better workflow | Consistent task contract, scoped searches, retained uncertainty | Markdown can instruct a parent and documented agents, but reliability, interactive state and coverage are unknown. | Promising packaging; ordinary orchestration by itself is not novelty. |
| C. Better interaction | Compare consequences, ask a decision, then update | Textual alternatives are possible in principle; generic G already generated them. UGREEN follow-up persistence is unverified. | Worth testing with people; no custom UI assumption. |
| D. Better output | A pitch, exercise or report a person can actually use | Local question card was manually curated; invoice results were simple. No independent user usefulness measured. | Most tangible opportunity if a real user changes a decision. |
| E. Unexpected capability | Recombine forgotten assets and expose constraints | A creative direction plus cited rights can be proposed, but relevance, originality and legal interpretation remain unverified. | Most creative plausible candidate; needs an adversarial creator test. |

## Defensible comparisons

- **Creative Salvage:** “A generic file assistant can propose ideas and inspect supplied rights; our proposed Skill would package two alternative, source-linked creative pitches with explicit holds through bounded native expert delegation.” The delegation is documented; the full mechanism and advantage are **not yet verified**.
- **Fork & Finish:** “A generic file assistant can already compare conflicting records and write conditional outputs, as G did locally; our proposed Skill would standardize authorized retrieval and record the user's selected branch in a later report.” Retrieval actions are documented; preservation across turns is **not verified**.
- **Knowledge Succession Rehearsal:** “A generic assistant can make a handoff exercise; our proposed Skill would guide a user through one task using scoped NAS evidence and explicitly identify unresolved steps.” Individual delegation actions are documented; the end-to-end rehearsal and user value are **not verified**.

No finalist currently meets the wording “verified mechanism” as a claim of actual NAS execution. These sentences specify the intended mechanism and exactly what remains to be verified.
