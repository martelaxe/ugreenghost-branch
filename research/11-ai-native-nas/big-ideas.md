# Twelve AI-native NAS product visions

These are inventions to investigate, not claims of global novelty or UGREEN roadmap. Three are new as specific interactions for this project (marked **new direction**); they reuse common enabling ideas and may already exist elsewhere. A model with the same file access may perform each MVP; none has proven superiority. Future visions assume capabilities explicitly marked speculative, not available in the submitted Skill. In each card the 60-second demo is a proposed visible result, not a live device result.

## 1. Impact Rehearsal

**Promise / user / problem:** Preview how a planned storage change may affect existing work; for NAS owner consolidating project files, where A single moved asset may be referenced from several places. **Request:** “Before I move this file, show me what could be affected.” **Uses:** authorized target, project notes and explicit path references.

**60-second WOW:** one file connects to two apparently unrelated projects. **Result:** source-backed impact map plus one safe next step. **NAS role:** storage holds the target and referring records in one authorized scope; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator Obsidian link updates / Premiere Link Media.

**3–5 year vision (speculative):** live cross-app dependency evidence and reversible change rehearsal. **MVP:** read-only bounded text-path preview. **Main technical risk:** unavailable source paths and hidden app dependencies. **Falsify value:** real users cannot act on the preview or real expert outputs lack source references.

## 2. Rebuild Kit

**Promise / user / problem:** Turn abandoned project records into a small ready-to-edit restart artifact; for maker, where unfinished notes and resources never become a next action. **Request:** “Help me make something useful from this paused project.” **Uses:** project notes, field notes, rights and resource limits.

**60-second WOW:** two scattered notes become a draft four-panel guide. **Result:** complete handout plus prerequisites. **NAS role:** persistent archives retain work-in-progress and constraints; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator Canva Magic Write / generic Codex.

**3–5 year vision (speculative):** cross-media creation with consent and user-authored approvals. **MVP:** text-only handout with sources and unknowns. **Main technical risk:** licensing inference or invented physical assets. **Falsify value:** creators prefer an ordinary prompt or cannot use the draft.

## 3. Decision Fork

**Promise / user / problem:** Make competing source interpretations visible as actionable alternatives; for small team owner, where uncertain version affects a real decision. **Request:** “Show the consequences of either unapproved quote.” **Uses:** two quotes, change rules and budget.

**60-second WOW:** the same project is $40 under or $40 over. **Result:** two conditional budgets and a decision question. **NAS role:** records live across project folders; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator Excel What-If.

**3–5 year vision (speculative):** live evidence-linked decisions and version-aware updates. **MVP:** one-shot sourced comparison. **Main technical risk:** silent approval assumption and incomplete costs. **Falsify value:** users find no benefit over ordinary spreadsheet analysis.

## 4. Negotiation Rehearsal — new direction

**Promise / user / problem:** Rehearse a real negotiation without sending anything; for a freelancer whose evidence, constraints and possible concessions are scattered. **Request:** “Help me prepare for a contract renewal using these selected files.” **Uses:** authorized contract, prior invoice and user-specified goal and boundaries.

**60-second WOW:** A mock counterpart challenges a proposed rate, and a source-backed response surfaces an overlooked contractual limit. **Result:** a short role-play transcript plus verified facts, open questions and a draft question for a human. **NAS role:** it may hold a history of a specific relationship; that advantage needs testing. **Generic AI / competitor:** a generic assistant can already role-play and analyze contracts; no unique mechanism is established.

**3–5 year vision (speculative):** Multi-turn, evidence-aware rehearsal with explicit user control over which context is included and never automated negotiation. **MVP:** one read-only text exercise based on a bounded fictional folder, with hypothetical responses clearly labeled. **Main technical risk:** invented counterpart intentions, unsupported legal interpretations or false authority. **Falsify value:** real freelancers find it generic, inaccurate, or no better than a simple assistant prompt.

## 5. Format Exit Passport — extends earlier preservation work

**Promise / user / problem:** Plan a documented exit from an old file format or application; for independent creator, where old projects may depend on a disappearing application. **Request:** “What would I need to reopen this old project elsewhere.” **Uses:** file names, user notes, existing exports and manuals.

**60-second WOW:** an export is present but linked source is absent. **Result:** per-project portability checklist and missing questions. **NAS role:** NAS retains old files and project context; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator digital preservation inventories.

**3–5 year vision (speculative):** real format validation and supported conversion across software. **MVP:** read-only report of explicit records; no conversion. **Main technical risk:** extension alone does not prove a file can or cannot open. **Falsify value:** owners cannot verify a meaningful next step.

## 6. Skill Recipe Review — new direction

**Promise / user / problem:** Let an owner review a suggested reusable workflow before using it again; for NAS power user, where repeated multi-step tasks need trustworthy instructions. **Request:** “Draft a reusable procedure for this task and explain what must be approved.” **Uses:** user-authorized example records and prior explicitly supplied notes.

**60-second WOW:** an assistant proposes a small procedure and a counterexample that might break it. **Result:** a draft procedure with tests, version and approval points. **NAS role:** a storage appliance can keep owner-approved procedures and test examples; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator SkillOpt / generic agent Skills.

**3–5 year vision (speculative):** offline evaluated edits, held-out cases, versioning and rollback with explicit user control. **MVP:** one human-reviewed text draft; no persistence or self-modification. **Main technical risk:** self-edits would need unsupported runtime and trustworthy evaluations. **Falsify value:** bounded edits cause more failures or no measurable usefulness.

## 7. Credit Ledger — new direction

**Promise / user / problem:** Prepare a human-reviewed credits draft from scattered project records; for a community creator who may forget a contributor or confuse a contribution. **Request:** “Draft credits for this finished project from these selected files.” **Uses:** authorized notes, attribution terms and file manifests.

**60-second WOW:** The draft names a documented role and shows an unresolved contributor record instead of inventing a credit. **Result:** an editable credits list, evidence paths and questions for the project owner. **NAS role:** accumulated project artifacts and earlier agreements may be stored together; that advantage needs testing. **Generic AI / competitor:** a generic assistant can draft credits from the same files; [Adobe's Content Credentials](https://experienceleague.adobe.com/en/docs/cx-enterprise-ai/experience-cloud-ai/overview/content-transparency) documents provenance metadata, a related but different mechanism.

**3–5 year vision (speculative):** Trace contribution history across project applications with participant consent and user-confirmed attribution. **MVP:** a read-only text-only credits draft with explicit unknowns and no automatic publication. **Main technical risk:** inaccurate identity matching or omission of off-device work; a record is not legal ownership proof. **Falsify value:** creators cannot verify claims or prefer an ordinary assistant's credits draft.

## 8. Resource Swap Ledger

**Promise / user / problem:** Identify alternatives when a planned activity lacks one documented resource; for community organizer, where a plan depends on unavailable equipment. **Request:** “Find a way to run this event without the projector.” **Uses:** brief, available-resource note, user restrictions.

**60-second WOW:** a prior paper exercise replaces an unavailable projection. **Result:** one practical text activity and prerequisites. **NAS role:** reuses materials already stored over time; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator generic AI / creative DAM.

**3–5 year vision (speculative):** resource-aware proposals spanning actual media and permissions. **MVP:** one source-backed alternate activity. **Main technical risk:** false inference of equipment availability or permission. **Falsify value:** no new actionable substitute survives evidence review.

## 9. Archive Continuity Drill

**Promise / user / problem:** Let a second person practice finding and following an owner’s handoff instructions; for home server administrator, where a spouse may not know how to use a stored plan. **Request:** “Give my partner a short handoff practice task.” **Uses:** owner-selected notes and explicit task.

**60-second WOW:** a missing instruction becomes visible while the owner can answer. **Result:** a question card and missing-evidence list. **NAS role:** shared personal records support the handoff; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator OneDrive digital legacy / generic AI.

**3–5 year vision (speculative):** verified human drills and optional approved updates. **MVP:** a read-only text exercise. **Main technical risk:** false impression that the backup was tested. **Falsify value:** a real successor gains nothing or a critical action is incorrect.

## 10. Evidence Gap Lantern

**Promise / user / problem:** Identify what a real task requires that the reviewed records do not establish; for small business worker, where reports can look complete when inputs are unavailable. **Request:** “Make this report and tell me which needed facts remain unknown.” **Uses:** agreement, document inventory and source records.

**60-second WOW:** a missing month is actually a documented no-work exception. **Result:** a conditional report and a precise question. **NAS role:** NAS scope makes files accessible to native experts; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator invoice-agent / Microsoft Payables.

**3–5 year vision (speculative):** task-aware retrieval across multiple authorized sources. **MVP:** one incomplete report with caveats. **Main technical risk:** absence wrongly treated as nonexistence. **Falsify value:** a safe generic agent already does the same with equal ease.

## 11. Sidecar Context Map

**Promise / user / problem:** Show how user-written descriptions connect media to projects without changing metadata; for photographer, where asset meaning is separated from files. **Request:** “Show which notes refer to this selected photo.” **Uses:** selected image metadata, captions and project notes.

**60-second WOW:** a forgotten caption explains an ordinary image. **Result:** reviewable source map and unknown identity. **NAS role:** personal photo archives and notes coexist; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator Immich / MemoryJam.

**3–5 year vision (speculative):** cross-media history with user-confirmed identity. **MVP:** text-only sidecar/reference report; optional photo expert. **Main technical risk:** image identity and consent cannot be inferred reliably. **Falsify value:** wrong linking or no meaningful user value.

## 12. Recovery Storyboard

**Promise / user / problem:** Turn explicit recovery notes into a testable human walkthrough; for household or team, where having backups does not mean a person can restore. **Request:** “Create a practice walkthrough from these recovery notes.” **Uses:** selected recovery documents and explicit expected steps.

**60-second WOW:** the plan has an unverified missing step. **Result:** practice script with cited unknowns. **NAS role:** NAS stores the procedures beside its records; this advantage needs testing. **Generic AI / competitor:** generic Codex can attempt this with the same access; nearest comparator backup vendor recovery guides.

**3–5 year vision (speculative):** real restore drills with checks and verified capabilities. **MVP:** one fictional read-only rehearsal. **Main technical risk:** cannot certify backup or recovery. **Falsify value:** a successor cannot use it safely or it promises successful restore.
