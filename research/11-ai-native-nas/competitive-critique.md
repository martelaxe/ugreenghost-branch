# Product and competition critique

**Ordinary NAS owner:** “I am about to tidy a shared folder; will I break anything?” The Skill offers a short evidence-linked preview and review step. This only helps when relevant references are actually retrievable; false reassurance could be worse than no feature. User appeal has not been independently demonstrated.

**UGREEN product team (hypothetical):** A coherent appliance experience could give owners a chance to understand cross-folder consequences before approving changes. The native storage context matters because target and referenced documents may already live there. UGREEN has not stated this is on its roadmap; its first-party assistant may already do much of it. Neither convenience nor automatic privacy has been established.

**Skeptical engineer:** “A generic prompt and a text search can do this.” Correct in the local fixture: generic Codex produced the same two-reference map and uncertainty. A declarative Skill adds an invocation pattern, limits, parent/child routing and a consistent desired report; it does not create a new dependency scanner, programmatically enforce permissions or guarantee reliable evidence. The biggest differentiator must be a tested native user experience, not a promised intelligence increase.

**Existing tools:** [VS Code Java refactoring](https://code.visualstudio.com/docs/java/java-refactoring) can preview affected files for supported language refactors; [Adobe Premiere Link Media](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/locate-and-link-offline-files.html) locates and relinks missing media in its own projects; [Obsidian link management](https://help.obsidian.md/links) and link-checking extensions address note references. These already solve portions of path changes and may outperform a language model inside their own domain. The potential distinction is a text-based, user-directed cross-folder preview spanning records from more than one app, **if** UGOS experts can actually return the evidence. We did not prove competitors lack it.

**Current hackathon overlap:** The [official gallery](https://ugreenhackathon.devpost.com/project-gallery) was not published during this research; it cannot be treated as an empty list. The public [ClaimReady](https://devpost.com/software/claimready-home-inventory) entry describes evidence-linked household inventories and missing proof, not the exact proposed pre-move flow. Its claims are self-reported, and we cannot enumerate all submissions or Skills Hub entries. A similarly named competing Skill could exist.

**Biggest rejection:** It is an LLM plus ordinary file search wrapped in a prompt, with incomplete NAS coverage and no evidence of better outcomes. A more impressive-looking demo must not imply complete dependency detection, app repair, backup verification or reversible moves.
