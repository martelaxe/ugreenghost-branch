## Shortlist and top three

Five considered: **impact + copy roles**, **Project Rescue**, **Creative Salvage**, **Living Archive**, **restore-sample comparison**. This selection is a judgment about the current platform rather than a hard ranking by sum alone. The first three get closer scrutiny:

1. **Impact + selected copy roles** — Short invocation: “Before I move this, what might I affect?” User supplies a target, intended action and authorized scope; the procedure identifies direct vs ambiguous references, possible role differences, evidence and what was not checked. No approved write is needed for the core outcome. Native search and a generic agent can perform much of it; neither our current tests nor SkillHub pages prove distinct superiority. A judge may call it ordinary search with safety instructions.
2. **Project Rescue** — “Find the right missing file and put it back.” Best tangible outcome; local G/S both identified the asset, and a local adapter copied it. No atomic no-overwrite guarantee, approval resumption or real NAS copy. If the action cannot be safely demonstrated, its hook degrades to an ordinary search report.
3. **Creative Salvage** — “Find a way to reuse this abandoned project.” Surprising possibility and explicit rights challenge; local synthetic G/S both found the important combination. No actual creator preference, uncertain evidence propagation, a weaker single user-visible action.

**Winner: Before You Move — FALLBACK FLAGSHIP.** Conceptually it answers one decision: what may be affected by the owner's intended change? Copy-role review is relevant only when that change is consolidation. The improvement over Experiment 11 is a coherent, concrete classification and optional actual hash/role comparison, limited scopes and precise states, not a new dependency-graph algorithm. This is selected over Project Rescue because its core can remain read-only when the real atomic-write contract is unknown, and over the creative alternatives because it uses persistent NAS storage for an immediate, recognizable decision. The improvement is **not yet proven** to change outcomes or save time against generic Uliya.

Separate design considerations: short invocation requires target/action/permission; reusable procedure reduces instructions but adds necessary scope questions; multiple real branches exist; user gets a sourced decision preview; 60-second demo is potentially visual in actual Uliya text but not verified; official File Search and generic assistant are strong competitors; actual return fields, expert ordering and complete scope are critical unknowns; package/static checks are feasible before deadline. Copy-role branch is only materially useful when actual paths, hash results and role evidence all return.
