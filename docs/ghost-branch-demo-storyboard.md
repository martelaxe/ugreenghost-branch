# Ghost Branch demo plan

**One sentence:** Find forgotten software work in the files Git may never have seen, and prepare an evidence-backed investigation handoff.

**20 seconds:** “My NAS contains old backups of a project. Ghost Branch searches them for useful work—and tells me when an old idea was deliberately rejected or already exists.” Show the fictional project's current and laptop folders, not a claim about actual Git history.

**60 seconds:** Open actual UGREEN if available; authorize current, laptop and archive scopes. Ask for old work worth reconsidering. Show the real returned `rollupCsv.ts`, pilot note and screenshot, followed by the review note rejecting remember-browser and the migration note showing that title search moved. Show the packet with source paths, formula-injection uncertainty and suggested future tests. If the expert does not return usable evidence, show the limitation instead. Do not imply a screenshot proves the export ran.

**Three minutes:** (0–30 seconds) project and scope; (30–90) CSV prototype/pilot/log and compare current snapshot, including unknown separate service; (90–130) security-rejected login and current-equivalent search; (130–170) coding-agent packet, including both positive and contradictory evidence and future tests; (170–180) “Your repository remembers what you committed. Ghost Branch investigates what you left behind.” If available, demonstrate optional packet save only after actual approval and confirmed safe semantics; a pending or failed save is shown as such.

**Synthetic files:** `laptop/src/reports/rollupCsv.ts`, `laptop/notes/pilot.md`, `laptop/screenshots/pilot-ledger.png`, `archive/logs/pilot-check.log`, `archive/logs/report-check.log`, `archive/issues/report-plan.md`, `laptop/src/auth/rememberBrowser.ts`, `archive/issues/session-review.md`, `laptop/src/ui/filterBox.ts`, `current/src/search/queryIndex.ts`, `current/docs/search-migration.md`. Fixture source and screenshot are fictional and never executed in this research.

**Supported operations to request:** `file-agent` `ug-filesystem:find`/`cat`; `document-agent` `ug-document:qa`/`reconcile`; optionally `photo-agent` `ug-photo:vision-vlm` or `vision-ocr`; optional `knowledge-agent` `ug-knowledge:collect-evidence` and approved `save-text`. Parent delegates; it does not call child CLIs directly.

**Real-device unknowns:** source-code format and size limits; actual source path/excerpt propagation; screenshot input and image results; capped or unreadable listings; handoff across experts; save collision semantics, UI approval and actual completion. All must be shown with actual returned statuses. No custom interface, Git, remote access to a service, running code or automated branch creation is promised.
