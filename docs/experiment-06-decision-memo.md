# Experiment 06 decision memo

**Decision:** begin Round 1 preparation conditionally, using the Markdown-only `surprise-me` prototype as a draft. Do not claim the workflow has run on UGREEN hardware or that it delivers verified real-world discoveries. Before submission, check the current rules and starter kit, document the remaining gaps, and distinguish static validation from device validation.

1. **What changed:** Discovery Engine V2 preserves original candidates and citations. Empty or failed verifier output now yields an explicitly unverified or insufficient-evidence state; a source-backed critical restriction yields `BLOCKED`, and uncited blockers cannot become verified. The user-facing report never recommends a preserved unsafe original action.
2. **What passed:** 32 deterministic local tests covered the three real Experiment 05 regression inputs, the required failure/approval/coverage cases, source checks and illustrative expert handoffs. The official UGREEN checker returned `static-pass` with zero errors and warnings for the Markdown-only prototype.
3. **What remains unproven:** Semantic judgments in the regression fixtures are manually supplied. V2 does not call a model, independently verify semantic truth or prove improved discovery accuracy. The Skill is instructions for a parent model and real experts, not the locally tested Python engine.
4. **Biggest NAS risk:** UGREEN's documented summaries do not guarantee actual source IDs, excerpts, coverage/truncation indicators or handoff schemas. Real model synthesis, disposition handling and incomplete-results behavior are untested. Missing data must be reported as unknown rather than marked checked.
5. **Product value beyond summary:** An on-demand investigation can combine multiple stored files into a candidate and disclose evidence, blockers and a safe next step. NAS fit comes from user-authorized stored data and documented native expert mappings. The reasoning and hypothesis generation still resemble generic AI prompting; the experiments have not shown a specialized intelligence advantage.
6. **Credible three-minute demonstration:** On the assigned NAS, if the real agents support it, investigate one prepared fictional folder, show a cross-file possibility with actual source references, then show a second folder with a documented blocker and the changed recommendation. Clearly report missing coverage. This is a plan, not an achieved demo.
7. **Avoid promising:** flawless semantic verification, comprehensive history, complete coverage, automated background monitoring, a persistent graph, automatic file moves or an intelligence multiplier. Do not represent simulated outputs or static checks as NAS evidence.
8. **Highest-value next step:** obtain actual sanitized delegate outputs or official clarification for source/coverage/handoff contracts, then test one read-only positive and blocked case on the real device when available. Validate genuine citations and graceful failure before making stronger claims.
