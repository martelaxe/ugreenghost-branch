# Ghost Branch — product specification

**Pitch:** Your repository remembers what you committed. Ghost Branch investigates what you left behind.

A developer points UGREEN's assistant to authorized current-project and old-backup folders and asks, “What old work is worth another look?” Ghost Branch is designed to assemble evidence from source snapshots, notes, logs and optionally screenshots; seek reasons for and against recovery; distinguish retired or superseded work; and prepare a concise coding-agent handoff. It never implies an actual Git branch, code execution, deployment or a discovered committed history.

The NAS matters when it holds off-repository artifacts unavailable from an ordinary Git log: a laptop copy, an exported review, an internal mockup or a historic log. A generic AI agent with equal access can investigate the same data. Ghost Branch packages the specific procedure, categories and handoff; greater reasoning ability, global novelty, user demand or a comparison win are not established.

Three modes: **discovery** (find likely candidates), **focused investigation** (trace an owner-named feature), and **packet preparation** (handoff for a chosen candidate). Output: source-backed candidate and caution, inspected vs unknown scope, evidence for and against, classification and concrete future tests. Optional text saving requires explicit user authorization, documented expert approval, and confirmed safe destination/collision behavior; an unavailable write does not block the in-chat packet.

The [fictional Lantern Ledger archive](../experiments/ghost-branch/fixtures/lantern/) is an intentionally constructed demonstration, not real user history. CSV export has evidence of useful prototype work but unknown current implementation and formula risks; a remember-browser experiment was explicitly rejected in a saved security review; a title filter moved to a current search implementation. The screenshot is a generated mock interface, and the archived test logs are fictional records—not tests executed by Ghost Branch.

No real UGREEN expert, owner or NAS was involved. A parent Skill cannot run Git, build or test code, call arbitrary APIs, create a branch or guarantee full coverage. If only a source is found, the result is a qualified hypothesis, not a verified working feature.
