Before You Move
Round 1 proposal — review draft
1. What does the Skill do?
Before You Move is designed to preview evidence of what a proposed file change might affect.
2. Who is the target user and problem?
NAS owners consolidate or reorganize long-lived files but may not know which projects use a particular copy.
3. What is the solution?
A read-only investigation aims to distinguish direct references, ambiguous matches, different copy roles and unknown
dependencies before the owner decides.
4. What is the core user flow?
The owner identifies the target, change and authorized folders. The Skill requests bounded discovery and reference
review, optionally requests a copy comparison, and reports returned evidence, limitations and a specific next step.
5. How does it differ from existing tools or common AI?
It packages a pre-change procedure that separates byte identity from file roles and makes unchecked dependencies
visible. Local tests showed generic AI, including a detailed prompt, can produce similar findings; no superiority has been
established.
6. Which UGREEN AI NAS capabilities does it use?
The Skill requests file-agent discovery and selected hashes, document-agent reference review, and optionally
knowledge-agent supporting and contrary evidence, where supported results are returned.
7. What is the technical approach?
The Markdown instructions direct delegation to registered experts for documented filesystem, document and knowledge
operations. The owner authorizes the scope; the core requests no changes. Model and any external processing depend
on device configuration.
8. What is built and what needs testing?
The Skill instructions pass the official static checker. Local Codex tests on fictional files compared ordinary, detailed and
Skill-guided requests; none used UGREEN agents. Device execution, source propagation and coverage remain
unverified.
9. What will finalists test?
First, inspect an asset before a proposed move when two documents reference it. Second, compare identical copies with
one referenced role and one unknown role. Edge case: an essential reference lies outside the authorized scope; request
authorization and report uncertainty.
10. What are the limitations and dependencies?
The Skill is not designed to observe all applications, prove a deletion safe, move files, restore backups or maintain a
dependency graph. Expert result formats, completeness and configured model behavior require hardware testing.
